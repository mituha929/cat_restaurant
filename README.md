# 貓咪主廚工作坊 Cat Chef Workshop

一款以貓咪客人、料理製作與時間管理為主題的網頁小遊戲。玩家需要依照顧客訂單，拖曳食材完成料理並出餐，在有限的耐心時間內累積金幣與經驗值。

## 專案特色

- 以 8 種食材與 16 道料理組成的拖曳式烹飪系統。
- 支援壽司模具、飯糰模具、瓦斯爐與烤箱等不同製作流程。
- 貓咪顧客會依座位從左側、上方或右側走入，並以兩張走路圖片產生步行效果。
- 顧客有耐心進度條；完成訂單可獲得金幣與經驗值。
- 食材具有庫存、補貨與庫存顏色提示：綠色為充足、黃色為偏低、紅色為不足。
- 老鼠突襲事件會偷取食材、料理或金幣，玩家可快速點擊老鼠阻止偷竊。
- 升級後會進入 Fever Time，獲得雙倍金幣與加速效果；後期可進入無限模式。
- 提供食譜圖鑑、詳細文字步驟、遊戲說明與 ESC 關閉視窗操作。
- 具備開場劇情動畫、星空與流星特效，以及自動播放的廚房影片結尾。
- 已加入電腦與手機版的響應式版面設計。

## 如何開啟

本專案不需要安裝套件或啟動後端伺服器。

1. 直接以瀏覽器開啟 `index.html`。
2. 在開始畫面點選「開始遊戲」。
3. 若要觀看獨立的前導動畫預覽，可開啟 `intro_animation_preview.html`。

> 專案使用 GSAP、GSAP Draggable 與 Anime.js 的 CDN 版本；首次開啟時需要網路連線載入這些動畫函式庫與 Google Fonts。

## 遊戲操作

| 操作 | 說明 |
| --- | --- |
| 拖曳食材 | 從食材補給區拖曳食材至出餐準備區，依照正確順序製作料理。 |
| 使用器具 | 將待料理放上瓦斯爐或烤箱，並依器具操作完成烹飪。 |
| 出餐 | 把完成料理拖曳至點餐的貓咪客人。 |
| 補貨 | 點選食材卡片上的「補貨 $100」按鈕。 |
| 清除失敗料理 | 將錯誤食材或焦黑料理拖到垃圾桶。 |
| 防止老鼠偷竊 | 老鼠出現時快速點擊 3 次。 |
| 暫停選單 | 使用上方「暫停」按鈕開啟導覽功能。 |
| 關閉說明或圖鑑 | 點選右上角關閉按鈕，或按下 `ESC`。 |

## 食材庫存提示

食材卡片下方的庫存條會依數量變色：

- 綠色：數量大於 7。
- 黃色：數量大於 3 且小於或等於 7。
- 紅色：數量小於或等於 3。

## 使用技術

| 技術 | 用途 |
| --- | --- |
| HTML5 | 遊戲畫面、彈出視窗、影片與無障礙文字結構。 |
| CSS3 | 響應式版面、卡片懸停、浮動對話泡泡、警告閃爍、流星、漣漪、進場與走路動畫。 |
| JavaScript (ES6) | 遊戲狀態、食譜判定、計時器、經驗與金幣、庫存、補貨、老鼠事件與鍵盤操作。 |
| GSAP + Draggable | 食材與料理的拖曳互動、顧客與介面進場動態。 |
| Anime.js | 食材架與老鼠等交錯、補間動畫。 |
| Web Audio API | 以程式產生遊戲音效與背景音樂，不依賴外部音樂檔案。 |
| Canvas | 料理完成與升級時的彩帶粒子效果。 |
| LocalStorage | 儲存無限模式的排行榜成績。 |

```text
├─ png檔案說明.txt                 # 圖片素材說明

```

## 主要程式模組

- `INGREDIENTS`：食材名稱、解鎖等級與圖示設定。
- `RECIPE_LIST`：料理所需步驟、器具、時間與完成圖片。
- `state`：集中管理玩家等級、金幣、庫存、顧客、器具及事件狀態。
- 食材系統：處理拖曳、庫存扣除、單一卡片更新與補貨。
- 顧客系統：產生訂單、耐心倒數、走路進場與成功出餐。
- 老鼠系統：移動、點擊防禦與偷竊後的狀態清除。
- 前導系統：12 幕劇情動畫、星空效果與影片播放。

## 注意事項

- 請保留 `assets`、`cat_walk` 與 `gemini_photo` 資料夾，否則遊戲圖片、走路動畫或前導動畫可能無法顯示。
- 料理步驟必須符合食譜的食材順序；錯誤組合會產生焦黑失敗料理。
- 若直接以檔案方式開啟後有瀏覽器限制，可使用任一簡單的本機靜態伺服器開啟專案根目錄。
